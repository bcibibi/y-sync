# @bcibibi/y-sync-test

> Beta: this workspace is currently in beta and setup/coverage may evolve.

Integration and regression test workspace for y-sync.

## Run Tests

From the repository root:

```bash
npm -w test run test
```

From the `test` folder:

```bash
npm run test
```

## Watch Mode

```bash
npm -w test run test:watch
```

## Functional Coverage

This workspace covers, among others:

- document synchronization,
- awareness,
- memory provider,
- Redis integration,
- middleware Mongoose.
