# Security Policy

Security is important for y-sync.

## Reporting a Vulnerability

Do not publish sensitive details in a public issue.

Prefer using the private reporting feature of GitHub Security Advisories on this repository.

Please include when possible:

- estimated impact and severity,
- reproduction steps,
- affected version(s),
- temporary mitigation proposal.

## Response Timeline

- Acknowledgment target: 3 business days.
- Initial triage target: 7 business days.
- Fix or remediation plan: depends on severity and complexity.

## Responsible Disclosure

Please wait for a fix to be available before full public disclosure.
